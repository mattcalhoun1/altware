Communicate in a grid outage, securely

Blackout Comms is specialized firmware for exactly this case: text, location, and simple control with no grid services.

The design goal is a path that is hard to intercept, interfere with, or fake. That comes from asymmetric encryption on direct messages, digital signatures, and frequency hopping that is not a fixed channel.

  • Direct messages use public/private key encryption. Relays that help delivery cannot decrypt them. Symmetric encryption is used where a whole cluster must read the packet, such as a broadcast.
  • ECDSA signatures cover transmissions. Other cluster devices check the signature before they process or mesh the packet.
  • The cluster does not sit on one frequency. It hops across as many as 64 frequencies in a non-repeating pattern unique to that cluster.

There is no service plan, no phone app, and no radio license if you stay inside the transmit limits for the ISM band you are using. Range is a function of how many devices you place, where they sit, and which antennas or amplifiers you use.

Remote control over the same mesh — circuits, sensors, simple automation — is part of the platform and still expanding. A fuller feature list is on chatters.io.
